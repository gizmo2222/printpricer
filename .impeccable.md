# Impeccable Design Context — Print Pricer

## Design Context

### Users

A solo 3D-printing hobbyist using this for personal pricing — figuring out what to charge friends/family or for the occasional sale. Not a customer-facing storefront, not a high-volume Etsy operation. The user already lives in their slicer (PrusaSlicer, OrcaSlicer, Bambu Studio) and exports projects regularly.

### Primary context

Desktop, sitting at the slicer machine. After exporting a project, drag the `.gcode` or `.3mf` onto the calculator and read the breakdown. Calm, deliberate use — not a frantic mobile-in-the-workshop scenario.

### Brand Personality

Workshop. Drafting-pad. Engineering-honest.

It should feel like a tool you might find pinned next to a CAD workstation or in a fabricator's reference binder — purposeful, measured, slightly old-school technical. Not a SaaS dashboard. Not a slick D2C calculator widget. Not a dark-mode "techy" UI.

### Aesthetic Direction — Workshop / Engineering Drawing

- **Surface**: warm cream / drafting-pad paper (`#f0e8d3`-ish), with a faint blueprint-blue grid as a background texture
- **Primary ink**: deep ink with a slight cool tint (`#16202d`)
- **Accent**: blueprint blue (`#1f4e7a`) — for emphasis, totals, structural rules
- **Stamp accent**: rust/brick (`#a13c1f`) — sparingly, for "saved" / committed-action moments
- **Pencil green**: `#4a6a3a` — for annotations and the moss-pencil hint
- **Display type**: `Big Shoulders Display` — bold, condensed, industrial-poster lineage (drafting-shop signage feel)
- **Body type**: `IBM Plex Sans` and `IBM Plex Sans Condensed` — engineering-pedigreed grotesque, made by IBM specifically for technical content
- **Tabular type**: `IBM Plex Mono` — for the cost breakdown table only, where alignment of decimals matters; used as functional dimensioning, not as decorative "techy" shorthand

### Specific motifs

- Title block in the upper-left corner like a real engineering drawing (project, drawing number, sheet, date)
- Numbered tabs / "layers" — `01 — ESTIMATE`, `02 — DEFAULTS`, `03 — ARCHIVE`
- Drawing blocks with corner bracket marks (small L-shapes), not rounded cards
- Dimension-leader breakdown rows: label · · · · · · · · · · · · · · · value
- Stamp-style "ESTIMATED PRICE" emphasis on the total
- Labels above inputs in small letterspaced uppercase like architectural callouts
- Subtle paper-grain background pattern + faint grid

### Anti-references

- No glassmorphism, no gradients, no neon
- No dark mode (this is paper, not a terminal)
- No Inter, Roboto, JetBrains Mono, or generic AI-stack fonts
- No rounded cards with drop shadow
- No purple-to-blue accents

### Design Principles

1. **Drafting honesty** — every visual element should look like it was drafted, not designed in Figma. Sharp corners, hard rules, dimension lines.
2. **Numbers are the hero** — the breakdown is a measurement table. Tabular numerals, aligned decimals, leader dots.
3. **Density is fine, decoration is not** — this is a working tool. Information density is good; ornamentation that doesn't earn its place is not.
4. **One stamp moment** — the total price gets the emphasis. Everything else is supporting structure.
5. **Page is the metaphor** — the screen is a sheet of drafting paper. Lean into it (margins, title block, sheet number).
