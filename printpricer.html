    Cost Formula

    Reference noteB
    filament = Σ ( grams ÷ 1000 × $/kg )
    electricity = ( watts ÷ 1000 ) × hours × $/kWh
    time cost = hours × $/hr
    subtotal = filament + electricity + time
    failure = subtotal × failure %
    margin = ( subtotal + failure ) × margin %
    total = subtotal + failure + margin
