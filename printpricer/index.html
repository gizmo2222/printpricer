    Print Pricer · Instructions

    Quick start

    1. Open 03 Printers and add at least one printer. Its wattage, hourly rate, and throughput drive every estimate.
    2. (Optional) Open 02 Spools and add the filament you have on hand. This auto-fills the cost on the Estimate sheet and tracks remaining grams as you print.
    3. On 01 Estimate, drag a .gcode or .3mf file onto the drop zone — print time and filament weight fill in automatically. Or enter values manually.
    4. Click Stamp & Archive to save the quote. You have 8 seconds to undo.

    The five layers

    01 Estimate
    The working sheet. Drop a file or enter values, see the cost breakdown live, stamp it.
    02 Spools
    Filament inventory. Color, material, $/kg, remaining grams. Spools below 50 g are flagged low. Each carries a refill log and a consumption forecast based on your archive.
    03 Printers
    Your workshop fleet. Each printer has its own wattage, $/hr, throughput, and multi-color overhead. Pick one per estimate.
    04 Defaults
    Workspace-wide values: filament $/kg default, electricity $/kWh, failure markup, profit margin, density and fill fraction for geometry estimates. Account & Group sign-in lives here too.
    05 Archive
    Saved estimates. Load to revisit, clone to start a similar print, print as a customer-ready quote, or export the whole list as CSV. Filter bar appears once you have 10+ entries.

    What files the app reads

    • .gcode from PrusaSlicer / OrcaSlicer / SuperSlicer / Cura — reads ; estimated printing time and ; filament used [g].
    • .3mf sliced from Bambu Studio / OrcaSlicer — reads slice_info.config (filament weights + prediction time) or the embedded gcode.
    • .3mf model-only (downloaded from MakerWorld / Printables, project saved before slicing) — falls back to geometry-based estimation: parses the mesh, computes volume × density × fill fraction, and proportions per filament by part-volume share. ±30% accurate; tune the factors in 04 Defaults.
    • Multi-plate 3MFs use the heaviest plate (the one most likely to be the substantive print).

    How the cost is calculated

    filament = Σ ( grams ÷ 1000 × $/kg )
    electricity = ( watts ÷ 1000 ) × hours × $/kWh
    time cost = hours × $/hr
    subtotal = filament + electricity + time
    failure = subtotal × failure %
    margin = ( subtotal + failure ) × margin %
    total = subtotal + failure + margin

    Cloud sync & group sharing

    The app works fully offline by default — everything stays in this browser's localStorage. Sign in (top-right OWNER cell, or in 04 Defaults) to sync your data across devices.

    Groups let multiple people share the same workshop. Create a group, get a 6-character join code, and anyone signed in with that code shares your spool inventory, printer fleet, archive, and defaults — all in real time. The active printer selection stays per-device.

    Tips

    • Linked spools auto-deduct grams when you Stamp & Archive. Refill any spool by editing it and clicking Refill to Xg.
    • Filament rows show a small color swatch when linked to a spool. Type a spool name in the type/color field to link it; cost auto-fills.
    • Click the join code in 04 Defaults to copy it.
    • The estimate sheet description always overwrites with the dropped file's name. Type your own after dropping if you want something different.
    • Sticky price tag (bottom-right corner) tracks the total whenever the main breakdown is offscreen.
