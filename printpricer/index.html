How it links

Reference noteB
On the Estimate sheet, the type / color field on each filament row is linked to this inventory: type a name that matches a spool, or use Pick to choose one. Cost auto-fills.

When you Stamp & Archive an estimate, grams used are deducted from the linked spools. Spools below 50 g are flagged as low. A consumption forecast (based on your last 30 days of archived prints) shows when each spool will run out.

    Cost Formula

    Reference noteC
    filament = Σ ( grams ÷ 1000 × $/kg )
    electricity = ( watts ÷ 1000 ) × hours × $/kWh
    time cost = hours × $/hr
    subtotal = filament + electricity + time
    failure = subtotal × failure %
    margin = ( subtotal + failure ) × margin %
    total = subtotal + failure + margin
